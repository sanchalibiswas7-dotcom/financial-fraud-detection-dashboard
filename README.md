# Financial Fraud Detection Dashboard

Built an interactive Financial Fraud Detection Dashboard using Tableau and SQL to analyze fraud trends, payment methods, merchant risk categories, and transaction behavior. Performed SQL-based data analysis and created visual insights to identify high-risk patterns and fraud activity.

## Tools Used
- Excel
- SQL
- Tableau

## Features
- Fraud trend analysis
- Merchant category risk analysis
- Payment channel fraud analysis
- Interactive dashboard filters

- Transaction trends

## Key Insights

- Fraud rate was around 1.8% of total transactions.
- Wire transfer and ACH payment methods showed higher fraud activity.
- Travel and retail categories had higher fraud occurrences.
- Fraud activity showed slight monthly fluctuations.
- Behavioral metrics helped identify suspicious transaction patterns.
